
# Assignment 2 - Express Portfolio

This is my personal portfolio website for Assignment 2.

## About the Website

I created this website using Node.js, Express, and EJS.

The website has these four pages:
- Home
- About Me
- Projects
- Contact Me

## Tools Used

- Node.js
- Express
- EJS
- Bootstrap
- Font Awesome
- CSS

## How I ran it

1. I opened the project in VS Code.
2. Then I opened the terminal.
3. Then I ran npm install.
4. Next I did npm start.
5. Finally, opened http://localhost:3000.

## Code Sources

The project structure was created using Express Generator.
Bootstrap and Font Awesome were used for the styling.
